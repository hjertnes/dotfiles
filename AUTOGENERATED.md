# dotfiles

Declarative software inventory and archived shell configuration for setting up Eivind's macOS development environment -- no application code, so there is no build, test, or lint suite.

## Build & Test

There is **no Brewfile in this repository** to run `brew bundle` against. The authoritative
one lives in the sibling `BrewBundle` project, and that is where installs are driven from:

```bash
brew bundle --file=../BrewBundle/Brewfile          # install everything declared
brew bundle check --file=../BrewBundle/Brewfile    # is every entry installed?
```

`Old/Brewfile` is an archived 2023 snapshot kept for history. It has diverged wholesale from
`BrewBundle/Brewfile` (81 entries against 127 lines) — do not install from it.

## Architecture

Every file is a manifest, a snapshot, or an archived config; `brew bundle` is the only tool that consumes anything here.

| Path | Purpose |
| --- | --- |
| `Brews` | Plain list of 27 formula names, no taps/casks/mas. Hand-maintained, consumed by nothing, and not the manifest — `BrewBundle/Brewfile` is. |
| `Apps.txt` | Snapshot of `/Applications` (115 entries). Reference only. |
| `Specification.md` | Prose statement of the repo's purpose, with a dated changelog at the bottom. |
| `Old/` | Archived legacy configs plus the superseded 2023 `Brewfile`, copied into place by hand -- per `Old/README.org` there is no linking script. |

`Old/` holds a complete `fish/` tree (`config.fish`, `conf.d/`, `functions/`, `completions/`, `fish_variables`, and a `fishfile` naming the fisher plugins jethrokuan/fzf, jethrokuan/z, rafaelrinaldi/pure, oh-my-fish/plugin-osx, RubieV/plugin-fuck -- whose files are vendored into those directories), plus standalone `gitconfig`, `zshrc` (oh-my-zsh, `dracula-pro` theme), `tmux.conf` (tpm plugins, dracula theme), and `tmux-session.yaml` (a tmuxinator layout over `~/Code/*` project directories).

## Key Details

- Standalone repo (`git@github.com:hjertnes/dotfiles.git`) living inside `Code/`; see the parent `Code/CLAUDE.md` for the project index. There is no parent build to run.
- `Brews`, `Apps.txt`, `Old/`, `Specification.md`, `CLAUDE.md`, and `AUTOGENERATED.md` are all tracked and committed; the working tree is clean. There is no `.gitignore`.
- `Apps.txt` is a 115-line snapshot of `/Applications` and has drifted from both `BrewBundle/Brewfile` and the real system. Reference only.
- `Old/fish/config.fish` and `Old/zshrc` hardcode the Intel Homebrew prefix (`/usr/local/bin`, `/usr/local/opt/go/libexec`); Apple Silicon needs `/opt/homebrew` paths.
- `Old/gitconfig` sets `filter.lfs.required = true`; installing that config on a machine without git-lfs breaks git.
- Both archived shells set `EDITOR=emacsclient` and alias `emacs`; the emacs config is a separate repo (hjertnes/emacs.d).
- `Old/zshrc` still aliases `brew cask upgrade`, a command modern Homebrew no longer accepts.
- Use the Fish shell for any scripting.
