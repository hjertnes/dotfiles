# dotfiles

Declarative software inventory and archived shell configuration for setting up Eivind's macOS development environment -- no application code, so there is no build, test, or lint suite.

## Build & Test

```bash
# Install everything declared in the Brewfile (taps, formulae, casks, Mac App Store apps)
brew bundle --file=Brewfile

# Check whether every Brewfile entry is installed
brew bundle check --file=Brewfile

# Regenerate the Brewfile from what is currently installed
brew bundle dump --file=Brewfile --force

# List installed formulae/casks not in the Brewfile (--force uninstalls them)
brew bundle cleanup --file=Brewfile
```

## Architecture

Every file is a manifest, a snapshot, or an archived config; `brew bundle` is the only tool that consumes anything here.

| Path | Purpose |
| --- | --- |
| `Brewfile` | Authoritative manifest -- 4 taps, 27 formulae, 6 casks, 44 Mac App Store (`mas`) apps. |
| `Brews` | Plain list of the same 27 formula names in the same order, without taps/casks/mas. Hand-maintained mirror, consumed by nothing. |
| `Apps.txt` | Snapshot of `/Applications` (115 entries). Reference only. |
| `Specification.md` | Prose statement of the repo's purpose, with a dated changelog at the bottom. |
| `Old/` | Archived legacy configs, copied into place by hand -- per `Old/README.org` there is no linking script. |

`Old/` holds a complete `fish/` tree (`config.fish`, `conf.d/`, `functions/`, `completions/`, `fish_variables`, and a `fishfile` naming the fisher plugins jethrokuan/fzf, jethrokuan/z, rafaelrinaldi/pure, oh-my-fish/plugin-osx, RubieV/plugin-fuck -- whose files are vendored into those directories), plus standalone `gitconfig`, `zshrc` (oh-my-zsh, `dracula-pro` theme), `tmux.conf` (tpm plugins, dracula theme), and `tmux-session.yaml` (a tmuxinator layout over `~/Code/*` project directories).

## Key Details

- Standalone repo (`git@github.com:hjertnes/dotfiles.git`) living inside `Code/`; see the parent `Code/CLAUDE.md` for the project index. There is no parent build to run.
- Only `Brewfile`, `Brews`, `Apps.txt`, and `Old/` are tracked in git. `Specification.md`, `CLAUDE.md`, and `AUTOGENERATED.md` are untracked, and there is no `.gitignore`.
- `postgresql@14` is declared with `restart_service: true`, so `brew bundle` starts it as a service on install.
- The 44 `mas` entries require the `mas` formula and a signed-in Mac App Store account, or `brew bundle` fails on them.
- `Apps.txt` has drifted from both the Brewfile and the real system -- it lists Alfred 5, Arc, BBEdit, and Docker, none of which the Brewfile installs.
- `Old/fish/config.fish` and `Old/zshrc` hardcode the Intel Homebrew prefix (`/usr/local/bin`, `/usr/local/opt/go/libexec`); Apple Silicon needs `/opt/homebrew` paths.
- `Old/gitconfig` sets `filter.lfs.required = true`, but git-lfs is not in the Brewfile -- installing that config without it breaks git.
- Both archived shells set `EDITOR=emacsclient` and alias `emacs`; no emacs is in the Brewfile, and the emacs config is a separate repo (hjertnes/emacs.d).
- `Old/zshrc` still aliases `brew cask upgrade`, a command modern Homebrew no longer accepts.
- Use the Fish shell for any scripting.
